# 本地划词翻译（Chrome 扩展）

选中网页文字后点击选区旁的“译”，使用 Chrome / Chromium 内置 Translator API 翻译为简体中文。

## 特性

- Manifest V3。
- 不整页翻译，只翻译你选中的文字；严格保留浏览器选区中已有的换行数量，不根据 HTML 文本块额外插入空行。网页按宽度产生的软换行不会写死，译文会随浮窗宽度自然重排。
- 浮窗底部可设置“点击页面其他位置时自动关闭”和原文语言。原文语言可选自动识别、英语、日语、韩语、德语、法语、西班牙语、意大利语、葡萄牙语或俄语，设置会保存在此扩展中。
- 浮窗右下角可像普通窗口一样拖拽调整宽度和高度。每次新翻译会按原文选区的宽度重新设定初始尺寸，不沿用上次的窗口大小。
- 浮窗底部设置区固定可见；缩小高度时仅译文区滚动。用户也可以加高窗口，译文区允许出现空白。
- 浮窗锚定在网页文档位置，不固定在浏览器视口；滚动页面时会随网页内容一起移动。
- 无广告、无账号、无 API Key、无第三方翻译服务器。
- 扩展不发起网络请求。Chrome 可能在首次需要该语言模型时自行下载模型，因此首次使用需要网络；后续翻译由浏览器内置模型完成。
- 仅请求 `storage` 权限，用于保存关闭行为和原文语言；不请求 `tabs`、`scripting`、`activeTab` 或后台网络权限。为在普通网页上显示划词按钮，扩展仅通过 content script 运行在网页中。

## 安装

1. 解压 `chrome_local_selection_translator.zip`。如果已看到同名文件夹，可直接使用该文件夹。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的 `chrome_local_selection_translator` 文件夹，注意选择文件夹本身，不要选择 `manifest.json`。
6. 打开网页，选中一段文字，点击选区旁的“译”。

## 首次使用与提示

- 第一次翻译某个语言时，Chrome 可能下载对应的本地模型。浮窗会显示“正在准备”或下载进度。请在此期间保持网络可用。
- 如果提示 Translator API 不可用，请先通过 Chrome 菜单的“帮助 → 关于 Google Chrome”更新浏览器。该 API 的可用性由 Chrome 版本、平台、语言模型和浏览器实验配置决定。
- 如果提示语言不支持，表示当前浏览器未给此设备提供所选语言到中文的本地模型。可切换原文语言后重试；扩展不会自动切换到任何在线翻译服务。
- 按 `Esc` 或点结果浮窗右上角的 `×` 可关闭。
- 默认情况下，翻译完成后点击网页任意其他位置也会关闭浮窗。取消勾选浮窗底部开关后，浮窗会保留，直到手动关闭或按 `Esc`。
- 调节宽高时，拖动译文浮窗右下角的斜纹手柄即可。调整宽度后，译文会按新宽度重新换行；下一次翻译会恢复为基于新选区的初始宽度。

## 已知边界

- Chrome 的内置 Translator API 不是所有 Chrome 版本和设备上都保证可用；扩展会给出本地提示，不会把文字发送给其他翻译服务。
- 仅处理前 6,000 个字符，避免意外选中超长网页内容。
- 某些受浏览器保护的页面，例如 `chrome://` 页面和 Chrome 网上应用店，不允许扩展注入，这是 Chrome 的限制。

## 文件说明

- `manifest.json`：Manifest V3 配置。
- `selection-translator.js`：划词按钮、翻译浮窗与 Translator API 调用。
