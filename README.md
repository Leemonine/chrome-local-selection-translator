# 本地划词翻译（Chrome / Edge 扩展）

选中网页文字后点击选区旁的“译”，使用 Chrome 或 Edge 内置 Translator API 在本机翻译。

## 浏览器版本要求

- Google Chrome 桌面版 **138 或更高版本**。Chrome 官方文档说明 Translator API 从 Chrome 138 稳定版开始提供。
- Microsoft Edge 桌面版 **148 或更高版本**。MDN 的当前浏览器兼容性数据记录 Edge 从 148 开始支持 Translator API。
- 版本达到要求仍不代表每台设备上的每个语种都一定可用。Translator API 仍属实验性能力，并可能受操作系统、地区、硬件和浏览器模型供应状态影响。扩展会在实际调用前检查可用性，不满足条件时显示提示，也不会转用第三方翻译服务。

参考资料：[Chrome Translator API](https://developer.chrome.com/docs/ai/translator-api)、[MDN Translator API 兼容性](https://developer.mozilla.org/docs/Web/API/Translator#browser_compatibility)。

## 特性

- Manifest V3。
- 不整页翻译，只翻译你选中的文字；严格保留浏览器选区中已有的换行数量，不根据 HTML 文本块额外插入空行。网页按宽度产生的软换行不会写死，译文会随浮窗宽度自然重排。
- 点击浏览器工具栏中的扩展图标，可以设置“点击页面其他位置时自动关闭”、原文语言、目标语言、语言互换和是否保存翻译历史。设置区位于历史记录上方，不占用网页翻译浮窗。
- 目标语言默认为简体中文。“自动识别”优先使用浏览器内置 Language Detector API；模型不可用、识别失败或短文本置信度不足时，会回退到本地字符规则，不会调用第三方服务。
- 网页划词浮窗右上角提供复制按钮，与关闭按钮并列。
- 翻译历史为可选功能并默认关闭。主动开启后，最多在扩展本地保存 200 条原文、译文、语言和时间，不保存网页地址；点击工具栏扩展图标可搜索、复制、单条删除或全部清除。
- 浮窗右下角可像普通窗口一样拖拽调整宽度和高度。每次新翻译会按原文选区的宽度重新设定初始尺寸，不沿用上次的窗口大小。
- 浮窗锚定在网页文档位置，不固定在浏览器视口；滚动页面时会随网页内容一起移动。
- 支持右键菜单“本地翻译选中文字”。普通网页以及 Chrome、Edge 的内置 PDF 查看器均可使用；PDF 译文显示在独立的小窗口中。
- 无广告、无账号、无 API Key、无第三方翻译服务器。
- 扩展不发起网络请求。浏览器可能在首次需要该语言模型时自行下载模型，因此首次使用需要网络；后续翻译由浏览器内置模型完成。
- 仅请求 `storage` 和 `contextMenus` 权限，分别用于保存设置和增加选中文字的右键菜单；不请求 `tabs`、`scripting`、`activeTab` 或后台网络权限。

## 安装

1. 解压 `chrome_local_selection_translator.zip`。如果已看到同名文件夹，可直接使用该文件夹。
2. Chrome 用户在地址栏打开 `chrome://extensions`；Edge 用户打开 `edge://extensions`。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的 `chrome_local_selection_translator` 文件夹，注意选择文件夹本身，不要选择 `manifest.json`。
6. 打开网页，选中一段文字，点击选区旁的“译”。

## PDF 和右键翻译

Chrome 和 Edge 的内置 PDF 查看器不允许普通扩展内容脚本直接插入选区按钮，因此 PDF 中不会显示红色“译”按钮。请按以下方式使用：

1. 使用 Chrome 或 Edge 打开带有可选择文字的 PDF。
2. 选中需要翻译的文字并点击右键。
3. 点击“本地翻译选中文字”。
4. 译文会在独立的小窗口中显示，可自动识别或选择原文语言、选择目标语言、互换语言、重新翻译、复制结果或开启历史记录。

普通网页也支持相同的右键翻译方式。

## 首次使用与提示

- 第一次自动识别或翻译某个语言时，浏览器可能下载对应的本地模型。浮窗会分别显示语言识别模型或翻译模型的准备和下载进度。请在此期间保持网络可用。
- 如果提示 Translator API 不可用，请先更新到上面列出的最低版本。Chrome 可打开 `chrome://settings/help`，Edge 可打开 `edge://settings/help` 检查版本。该 API 的可用性还取决于平台、地区和语言模型状态。
- 如果提示语言不支持，表示当前浏览器未给此设备提供所选语言到中文的本地模型。可切换原文语言后重试；扩展不会自动切换到任何在线翻译服务。
- 按 `Esc` 或点结果浮窗右上角的 `×` 可关闭。
- 默认情况下，翻译完成后点击网页任意其他位置会关闭浮窗。点击工具栏扩展图标并关闭对应开关后，浮窗会保留，直到手动关闭或按 `Esc`。
- 调节宽高时，拖动译文浮窗右下角的斜纹手柄即可。调整宽度后，译文会按新宽度重新换行；下一次翻译会恢复为基于新选区的初始宽度。

## 已知边界

- 内置 Translator API 不是所有浏览器版本和设备上都保证可用；扩展会给出本地提示，不会把文字发送给其他翻译服务。
- 仅处理前 6,000 个字符，避免意外选中超长网页内容。
- 某些受浏览器保护的页面，例如 `chrome://`、`edge://` 页面和扩展商店，不允许扩展注入，这是浏览器限制。
- 扫描版 PDF 如果没有文字层，鼠标无法选中文字；这类文件需要 OCR，当前版本不包含 OCR。

## 文件说明

- `manifest.json`：Manifest V3 配置。
- `selection-translator.js`：划词按钮、翻译浮窗与 Translator API 调用。
- `storage-bridge.js`：保存扩展设置。
- `background.js`：创建右键菜单并接收选中文字。
- `translate.html`、`translate.css`、`translate.js`：显示 PDF 和右键翻译结果的小窗口。
- `history.html`、`history.css`、`history.js`：工具栏弹窗中的设置、默认关闭的本地翻译历史、搜索和清理工具。
- `icons/`：扩展使用的 16、32、48 和 128 像素图标。
